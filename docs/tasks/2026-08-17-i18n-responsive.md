# Задача: адаптив (mobile) + локалізація

**Дата:** 2026-08-17  
**Статус:** done  
**Spec:** `docs/specs/2026-08-17-i18n-and-responsive.md`  
**Етап:** 1 MVP

## Мета

Закласти мобільну верстку і i18n так, щоб увесь подальший UI писався через словники й breakpoints, а не хардкод.

## Входить

- next-intl: локалі `uk` (default, без префікса) і `en` (`/en/...`)
- Словники для всіх поточних екранів
- Перемикач мови
- Мобільне меню, відступи, touch-target ≥ 44px
- Маршрути під `[locale]`

## Не входить

- Інші мови (pl, de…)
- Переклад шляхів (`/proyekty`)
- Повний паритет старого HTML-макета

## Критерій готовності

- `npm run lint` і `npm run build` проходять
- `/` українською, `/en` англійською
- На вузькому екрані меню відкривається кнопкою, контент не вилазить горизонтально
