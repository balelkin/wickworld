**Статус:** approved  
**Дата:** 2026-08-17

## Локалі

| Код | URL | Роль |
|-----|-----|------|
| `uk` | `/…` (без префікса) | default, основна мова продукту |
| `en` | `/en/…` | друга мова, той самий UI |

Бібліотека: **next-intl**. Рядки лише в `src/messages/{locale}.json`. У компонентах — `useTranslations` / `getTranslations`, не літерали українською/англійською (виняток: бренд `WickWorld`).

Навігація: `Link` / `useRouter` з `@/i18n/navigation`, не з `next/link`.

Нова мова = новий JSON + запис у `routing.locales`. Без окремого рефакторингу компонентів.

## Адаптив

- Mobile-first. Breakpoints: дрібні стилі за замовчуванням, `md:` десктоп-нав.
- Touch-target кнопок меню ≥ 44px.
- Navbar: гамбургер < `md`, повне меню ≥ `md`.
- Немає горизонтального скролу на 320px.
- `viewport-fit: cover` + safe-area для нижнього меню.

Редактор Wick (iframe) на етапі 1 може скролитись вертикально на телефоні — окремий UX редактора не в цій задачі.
