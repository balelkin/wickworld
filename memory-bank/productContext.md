# Product context

Портал має виглядати як дитячий креативний майданчик, не як адмінка. Вже є HTML-макет головної: `wickworld.html` + `styles.css` + `images/wwimage.png` (шрифти Baloo 2 / Nunito, жовто-синя палітра).

На MVP головне не лендінг, а **надійне збереження**: учень намалював → Save → закрив вкладку → відкрив знову → робота на місці. Якщо цей цикл бреше, продукт мертвий.

Save у хмару має бути зрозумілим (успіх / помилка). Не можна тихо затерти проєкт порожнім редактором.

Контент етапу 1 — приватний. Публікація і модерація — етап 2.
