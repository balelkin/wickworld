# Project brief

**WickWorld** — український дитячий портал для створення анімацій та ігор на базі Wick Editor.

**Девіз:** Творити, вивчати, ділитись.

**Аудиторія:** діти 9–16 років. Мова інтерфейсу: українська.

**Проблема:** діти переважно споживають контент (YouTube, ігри). Немає безпечного українського місця, де можна робити анімації в браузері, зберігати в хмарі і (пізніше) вчитися та ділитись.

**Не робимо зараз (після MVP):** галерея, ремікси, курси, гейміфікація, кабінет вчителя/модератора, власний редактор замість Wick.

**MVP (етап 1):** учень реєструється, має список своїх проєктів, відкриває Wick на нашому домені, Save/Load іде в хмару. Можна використовувати на уроці. Компроміс для вчителя — посилання «показати вчителю» (read-only), без кабінету вчителя.
