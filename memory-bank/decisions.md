# Decisions

## 2026-08-17 — ADR-001: стек порталу

**Рішення:** Next.js App Router + Supabase (Auth, Postgres, Storage) + Vercel.

**Чому:** один репо для UI і API, безкоштовний старт, RLS для дитячих акаунтів.

**Альтернативи:** окремий Express/Nest + власна Postgres; Firebase. Відхилено як зайва інфра на MVP.

---

## 2026-08-17 — ADR-002: Wick як форк, не iframe wickeditor.com

**Рішення:** форк `Wicklets/wick-editor` → `gromko/wick-editor`. Статичний білд на `/editor`. Iframe на тому ж домені. Save через `window.saveFileFromWick` + postMessage.

**Чому:** чужий origin не дає перехопити Save. Wick уже має платформний хук у `filehandler.js`. Ядро не переписуємо.

**Альтернативи:** iframe wickeditor.com (неможливо); свій редактор (занадто дорого).

**Наслідок:** два репо. Upstream не auto-merge. Форк GPL v3.

---

## 2026-08-17 — ADR-003: етап 0 (спайк) не окремий

**Рішення:** інтеграція Wick входить у етап 1 як перші задачі, не як окремий етап зі штатом.

**Чому:** розробка переважно одним розробником; окремий «спайк без UI» як кадрове питання не потрібен. Цикл Save/Load усе одно робимо першим, до кабінету.

---

## 2026-08-17 — ADR-004: процес агентів

**Рішення:** кожна задача: опис у `docs/tasks/` → погодження spec → код → `progress.md` → memory bank. Правила в `AGENTS.md` і always-on Cursor rules.

**Чому:** кілька агентів / сесій не повинні розʼїжджати архітектуру і губити контекст.

---

## 2026-08-17 — ADR-005: шари коду порталу

**Рішення:** `src/app` → `src/modules/*` → `src/shared`. Зовні модуля лише `@/modules/<name>`.

**Чому:** фічі ізольовані; спільне UI/env/result не тягне домен. Wick поза бандлом Next.

**Наслідок:** модуль `editor` зараз — host + типи `wickworld:*`, без iframe-білду.

---

## 2026-08-17 — ADR-006: i18n uk/en + mobile-first

**Рішення:** next-intl, default `uk` без префікса URL, `en` як `/en/…`. Рядки в `src/messages`. Navbar на мобільному — гамбургер.

**Чому:** український продукт, але архітектура локалізації з першого UI. Адаптив одразу, щоб не перекладати десктоп-верстку пізніше.
